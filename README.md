# クリスマス紙工作キット

クリスマスの紙工作3種を、大きな文字で1手順ずつ進めながら作れる単体HTMLアプリです。

## 工作（3種）
1. **立体ツリー** ― 十字に組み立てる立体ツリー
2. **ちぎって進むアドベントカレンダー** ― 12月1日〜24日の24マスを、毎日ちぎって進めるカレンダー
3. **ペーパーボールのオーナメント** ― 丸12個を貼り合わせて作るボール型オーナメント

## 特長
- 各工作に、完成イメージ・材料・作り方（大きな文字で1手順ずつ、前へ／次へで進む形式）
- 型紙はA4実寸（ミリ単位で設計、5cm確認線入り）。各工作の「型紙だけ表示」から、A4・倍率100％・余白なしで印刷
- 単体HTMLファイルのみで動作し、外部通信はしません。記録も保存しません

## 使い方
`index.html` をブラウザで開くだけで使えます（GitHub Pagesで公開）。
